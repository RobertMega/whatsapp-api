
## Contexto
Tenho um grupo no whatsapp no ual eu posto ofertas de produtos com meu link de afiliados do MercadoLivre, atualmente eu faço isso de forma manual, porem quero automatizar essas postagems. pretendo criar uma automação que periodicamente pegue os produtos do mercado livre gere o link de afiliado para coompartilhamento e faca as postagems no grupo.

### Tarefas
- Tenho uma API para envio de whatsapp já funcional, no momento ela tem as rotas para envio de Texto, Imagens e Arquivos, necessario adicionar uma rota nela para consultar os contatos e grupos do número conectado. preciso apenas apra eu verificar qual o id do grupo.

- Não sei se o Mercado livre fornece api para consulta dos produtos e geracao dos links caso forneca iremos utilizala para consultar e gerar o link e integramos com nossa api de postagem de whatsapp, caso nao forneca vamos criar um scraping usando playwright para abrir o mercado livre web e fazer a geracao dos links dos produtos e etc.

- Precisamos criar uma rotina de 05 postagems de a cada 10 minuto, então sera necessario um schedule para o gerenciamento do BOT.

- Apresente uma Stack Sugerida para criacao da desse robo
- Apresente a arquitetura para o projeto
